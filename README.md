# BudgetBlocks
### Scuffed Minecraft made with OpenGL

Welcome to **BudgetBlocks**, a questionable attempt at recreating Minecraft using OpenGL.

This is just a fun little project to experiment with OpenGL and build a basic Minecraft-like experience. We've got **dirt blocks. That's it.**

It's Minecraft, but on a budget.

## Features

- **Run around** – So you can explore every block of dirt.
- **Jump** – Because walking everywhere is boring.
- **Place blocks** – Build whatever your heart desires (with dirt).
- **Break blocks** – Destroy your questionable creations.
- **World generation** – Procedurally generated terrain to explore.

## Built With

- C++
- OpenGL

## Why?

Mostly because it's fun.

This project is a way to experiment with OpenGL, learn more about graphics programming, and see how far I can get with building a Minecraft-like game from scratch.

It's not meant to compete with Minecraft. It's meant to be scuffed Minecraft.
